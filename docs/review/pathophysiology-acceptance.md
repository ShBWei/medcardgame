# 病理生理学习题集导入验收

日期：2026-10-18；版本：6.5.6。当前验收对象为本地源码及生产构建。

## 导入范围

- 原书：《病理生理学学习指导与习题集》第2版，本地扫描 PDF。源文件哈希、逐章数量见 `pathophysiology-import.json`。
- 21 章共 1,243 题：858 道选择题、385 道主观题（含 34 道实验思考题）。
- 对战只使用选择题；刷题包含全部题型。主观题先回忆、再查看原书参考内容、自评掌握情况，记录复习计划，不计选择题正确率和排行榜积分。
- 原书未给出独立答案的实验题明确提示，不补造答案。实验二没有思考题；实验八的讨论内容已纳入。
- 168 张原书页面按需打开，不在首次进入游戏时全部加载。源码和生产目录均包含这些资源。

## 发现并修复的问题

- 首次加载科目时等待自身加载完成，导致题库无法返回。
- 题干包含方括号等内容时，题库数组解析可能提前截断。
- 主观题混入选择题缓存、对战题量或章节数量的风险；现在统一隔离。
- 主观题专场结算显示 0% 正确率，并触发无意义的排行榜提交。
- 混合练习后重练错题沿用主观题统计。
- 新增科目改变旧错题的数字科目编号。现固定历史编号，不受界面排序影响。
- 病生题目 ID 未被错题本科目分类识别。
- 部署缺少原书图片与服务缓存文件；已加入构建，并升级缓存版本。

## 验证结果

- 自动测试：4 个文件、54 项测试通过。覆盖全部题目的唯一 ID、答案映射、原书资源存在性；30 次完整牌组生成；主观题自评防重复计数；历史错题编码兼容；既有多人对战回归。
- 生产构建成功完成压缩：核心脚本 71.9 KB，游戏脚本 584.9 KB；复制 9 科题库和 168 张原书图片。
- 修改涉及的 JavaScript 静态检查：0 错误，6 项既有警告。
- 实际 Edge 浏览器：生产首页冷加载，858 道对战题 / 1,243 道刷题确认；主观题→选择题混合流程、草稿保留、自评防重复、选项打乱后答错/答对、结算统计均通过。
- 390px 手机宽度无横向溢出；原书页面返回 HTTP 200；旧 `medicard-v1` 缓存清理并启用新版缓存。
- 两个浏览器玩家使用病生原题完成正常连接及强制中继场景：加入、准备、开始、答错扣血、回合血量同步、答对防御、认输结束均通过，无浏览器异常。为稳定复现，牌组卡牌类型固定为攻击牌；另有完整随机牌组结构测试。
- 独立代码审查发现的问题已修复并复核，无剩余阻断项。

界面截图见 `pathophysiology-experience/`；可重复运行 `tools/browser-pathophysiology-check.cjs` 和 `tools/browser-match-check.cjs`（后者设置 `TEST_SUBJECT=pathophysiology`）。

## 验证边界

扫描书经两遍 OCR 与结构校验导入，保留原书页码及图像。结构完整性校验不等于逐字医学审校；复杂公式、上下标、单位或个别汉字仍可能存在识别误差，应对照原书。未开展跨公网、不同运营商的双人实机测试。不能以本次测试保证不存在任何缺陷。
