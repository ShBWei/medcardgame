### 镜头 4：服务器打包私有数据 → 本地下载（3:00-5:30）

| 项目 | 内容 |
|------|------|
| **画面** | 终端分屏：左侧 SSH 连接服务器，右侧本地终端 |
| **解说** | "现在演示从服务器下载私有数据。首先 SSH 登录服务器，cd 到项目目录。运行这条打包命令，把题库文件、数据库、配置文件打成一个压缩包。注意排除 node_modules 和 git 目录，它们不需要。打包完成后 ll 看一下文件大小。然后在本地的另一个终端窗口，用 scp 命令把压缩包下载到 Downloads 文件夹。" |

**关键命令展示**（大字体打在屏幕上）：
```bash
# 服务器端
ssh ubuntu@YOUR_SERVER_IP
cd ~/medcardgame
tar czf ~/backups/medcardgame-data-$(date +%Y%m%d).tar.gz *题库.txt data/ config/ .env
ls -lh ~/backups/

# 本地端
scp ubuntu@YOUR_SERVER_IP:~/backups/medcardgame-data-*.tar.gz ~/Downloads/
```

### 镜头 6：新服务器一键部署（7:00-8:30）

| 项目 | 内容 |
|------|------|
| **画面** | 终端全屏，SSH 登录一台新服务器 |
| **解说** | "接下来演示在新服务器上部署。假设你刚买了一台腾讯云服务器，Ubuntu 22.04 系统。首先 SSH 登录，git clone 拉取仓库。然后从本地把私有题库压缩包上传到服务器。最后运行一句 sudo bash deploy.sh，这个脚本会自动装好 Node.js 20、Redis、Nginx、PM2，配置好防火墙和开机自启。整个过程不超过五分钟。" |

```bash
ssh ubuntu@YOUR_NEW_SERVER_IP
git clone https://github.com/YOUR_USERNAME/medcardgame.git ~/medcardgame
cd ~/medcardgame

# 从本地电脑上传私有数据
# （在本地终端执行）：
scp ~/Downloads/medcardgame-data-*.tar.gz ubuntu@YOUR_NEW_SERVER_IP:~/medcardgame/

# 回到服务器终端：
tar xzf medcardgame-data-*.tar.gz
sudo bash deploy.sh
```

1. **剪辑节奏**：操作步骤部分保持 1:1 实时速度，解说部分可以 1.2x 微加速

3. **字幕**：全程添加中文字幕，关键命令使用等宽字体高亮
4. **敏感信息**：IP 地址、用户名等使用模糊处理
5. **章节标记**：B站投稿时添加视频章节（进度条分段），方便观众跳转
