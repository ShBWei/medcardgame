【开场白 — 0:00-0:20】

大家好，欢迎收听 MedCard Duel 医学刷题工坊的项目介绍。这是一款把医学题库和卡牌对战结合起来的学习工具。如果你正在准备医学考试，又觉得刷题太枯燥，这个项目就是为你准备的。


【项目介绍 — 0:20-1:00】

MedCard Duel 的核心创意很简单：借鉴三国杀的回合制卡牌玩法，把每张卡牌的效果判定改成答题。你出一张攻击牌，必须先答对一道医学题，才能造成伤害。答错了，卡牌就白费了。这就逼着你去认真复习知识点。

项目包含几个独立模块。想一个人安静刷题，有"医途刷题工坊"，六个主题皮肤随便换，八个医学学科、几十个章节随便选。想系统性地对抗遗忘曲线，有"快学模式"，用认知科学算法帮你智能安排复习时间。做错的题会自动收进错题本，每道题都有详细解析和干扰项分析。还有多人联机对战，支持两到五个人的身份局，主公、忠臣、反贼、内奸各有专属技能。


【本地开发教程 — 1:00-2:00】

如果你是开发者，想在本地电脑上修改代码，流程是这样的。

第一步，从服务器导出私有题库。SSH 登录你的腾讯云服务器，执行打包命令，把题库文本文件、用户数据库、配置文件打成一个压缩包。然后 SCP 下载到本地电脑。

第二步，克隆 GitHub 仓库。用 git clone 命令把项目源码拉到本地，把刚才下载的压缩包解压到项目目录里，运行 npm install 安装依赖。

第三步，用 VS Code 打开项目文件夹，配合 GitHub Copilot 就可以开始写代码了。修改完后，npm run build 验证构建，npx serve 在本地预览。确认没问题就 git push 推送到 GitHub。

服务器上更新也很简单：SSH 登录后 git pull 拉取最新代码，npm run build 重新构建，pm2 restart 重启应用，几秒钟就生效了。


【服务器部署教程 — 2:00-2:40】

如果是第一次把项目部署到一台新服务器，更简单。SSH 登录后，git clone 拉取仓库代码，从旧服务器把私有题库压缩包上传过来解压。然后运行一句 sudo bash deploy.sh，这个脚本会自动完成所有配置：安装 Node.js 20、Redis、Nginx、PM2，配好防火墙和开机自启。整个过程不超过五分钟。


【备份迁移 — 2:40-3:00】

如果你的旧服务器快到期了，需要迁移数据。项目自带备份脚本 backup-audit.sh，建议配置 crontab 每天自动备份。手动备份也很简单，执行 bash config/backup-audit.sh，然后把备份文件下载到本地保存。到了新服务器，解压还原即可。


【结束语 — 3:00】

最后总结一下。MedCard Duel 是一个完全开源的项目，GitHub 仓库地址在简介里。仓库里只有程序代码，题库和用户数据需要从你自己的服务器获取。有问题欢迎提 Issue，也欢迎提交 Pull Request 一起完善。

感谢你的收听，祝你学习愉快！
